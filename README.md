# Formation SQL Server - 40h

Dépôt contenant les fichiers de la formation "Formation SQL Server - 40h" : documents (Word & PDF en texte), scripts SQL d'exercices, et README.

Fichiers principaux:
- Formation_SQL_Server_-_40h.docx (contenu texte de la formation)
- Formation_SQL_Server_-_40h.pdf (même contenu, format texte)
- scripts/*.sql (scripts d'exercices et corrigés)

Liens de téléchargement recommandés (inclus dans les documents):
- SQL Server (Express / Developer): https://www.microsoft.com/en-us/sql-server/sql-server-downloads
- SQL Server Management Studio (SSMS): https://aka.ms/ssmsfullsetup
- Azure Data Studio: https://aka.ms/azuredatastudio
- LocalDB: https://learn.microsoft.com/sql/database-engine/configure-windows/sql-server-express-localdb
- Documentation Microsoft Learn (SQL Server): https://learn.microsoft.com/sql

Usage rapide:
1. Télécharger et installer SQL Server Express 2019 + SSMS (recommandé pour débutants).
2. Ouvrir SSMS, se connecter à l'instance locale.
3. Exécuter les scripts dans le dossier scripts/ dans l'ordre indiqué par les noms de fichiers.
